## Features
- Student name, enrollment number, email, mobile, gender, course, semester, hobbies and address fields
- AngularJS module and controller
- `ng-model`, AngularJS expressions and `ng-repeat`
- Required-field, email and 10-digit mobile validation
- Duplicate enrollment number prevention
- Registered students table and remove action
- Responsive layout for desktop and mobile

## Run locally
1. Extract the project folder.
2. Open `index.html` in a browser with an internet connection (AngularJS is loaded from Google's CDN).
3. Fill in the form and click **Register Student**.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `ayushi-student-registration`.
2. Upload `index.html` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the deployment. GitHub will show a website URL similar to `https://YOUR-USERNAME.github.io/ayushi-student-registration/`.
7. Open the URL and test registering a student. Copy the actual published URL into the GitHub Repo Link section of your assignment PDF.

> The app stores registered students in browser memory only. Refreshing the page clears the list; a backend/database was not required by the supplied assignment brief.
